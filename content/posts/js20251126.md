国产服务器正处于快速发展的阶段，特别最近这几年销量高速增长，不仅在政务、金融、电信等关键领域站稳脚跟，也开始向能源、交通、制造等行业进军，国产服务器使用国产操作系统，将成为未来服务器行业的一个新的发展态势。今天笔者给大家分享华启通用型服务器安装麒麟Kylin Linux Advanced Server V10 国产操作的过程。

这款服务器具体型号为华启DH-RS2197VL，它是基于鲲鹏920处理器的2U单路机架式服务器，提供企业级的强劲计算性能以及灵活可配置的 AI 计算能力，适合各类中小企业、工厂学校和商超等领域。

![e9f7fab3fb59bf3037414850202b6a2b.png](/img/e9f7fab3fb59bf3037414850202b6a2b.png)

下面通过iBMC带外管理口使用虚拟控制台安装麒麟 Kylin Server 国产操作系统

华启DH-RS2197VL服务器的开机的画面，可以看到BMC管理口的默认ip是192.168.1.100，准备一条网线把服务器的BMC管理口接入到局域网中  
![fb0a15bf3c52260f59703d4742484caa.png](/img/fb0a15bf3c52260f59703d4742484caa.png)

使用局域网中的一台电脑，打开浏览器，访问BMC管理口的ip： 192.168.1.100，即可进入BMC的登录界面，初始的用户名root，密码Admin123@dh  
![9a849f079c9035f99026a86892972318.png](/img/9a849f079c9035f99026a86892972318.png)

在页面的首页打开“虚拟控制台”  
![b3bed0e91e24b82283f745dd97624f16.png](/img/b3bed0e91e24b82283f745dd97624f16.png)

点击光驱图标，加载Kylin Server V10 操作系统的iso安装镜像，并连接虚拟光驱  
![edaedfc405e2835953d08a1bc7c39d1f.png](/img/edaedfc405e2835953d08a1bc7c39d1f.png)

连接好虚拟光驱后的状态  
![d4c02d77ae9bc3e3cefa5b2dc9c9303e.png](/img/d4c02d77ae9bc3e3cefa5b2dc9c9303e.png)

然后点击“系统启动项”图标，勾选“光驱”，表示将从光驱启动系统  
![09f4732632c24d8a8854270ac75f4004.png](/img/09f4732632c24d8a8854270ac75f4004.png)

再点击“电源控制”图标，重启服务器  
![e88c12f8d5ca09e51a06845b3d6d0bd3.png](/img/e88c12f8d5ca09e51a06845b3d6d0bd3.png)

重启后，就会从加载了系统镜像的虚拟光驱启动，进入麒麟Kylin Server V10 操作系统的安装程序  
![f09690f9a99adca31b9a991a47e2e3b9.png](/img/f09690f9a99adca31b9a991a47e2e3b9.png)

下面就正式进入麒麟 Kylin Linux Server 操作系统的安装界面

选项第一项安装系统  
![ef1ed299c807cc817025a41025d4211e.png](/img/ef1ed299c807cc817025a41025d4211e.png)

选择语言，这里选择简体中文  
![19fb1082f6b969e0ce6cb2c5128ace1d.png](/img/19fb1082f6b969e0ce6cb2c5128ace1d.png)

选择安装的目的地磁盘  
![7d0ca275dc1fa95a30495387c3859cda.png](/img/7d0ca275dc1fa95a30495387c3859cda.png)  

![d4ea4e92677dea45d08ffc8c1394878f.png](/img/d4ea4e92677dea45d08ffc8c1394878f.png)

因为原磁盘有数据，所以要回收空间，清除原有的硬盘分区  
![14cf25ee6e7c99657502f298aa5e1e3f.png](/img/14cf25ee6e7c99657502f298aa5e1e3f.png)  

![1a51fa0221acf151ebf97b20468cd606.png](/img/1a51fa0221acf151ebf97b20468cd606.png)  

![b4f81aa026efebcbce9f3d0b2a72eb50.png](/img/b4f81aa026efebcbce9f3d0b2a72eb50.png)

设置好root用户的密码，可以创建多一个用户。点击“开始安装”  
![64a8a636ce762fdda84a0431c9b7276a.png](/img/64a8a636ce762fdda84a0431c9b7276a.png)  

![5c8d4d3506aeeda5d756cf1fef3bc581.png](/img/5c8d4d3506aeeda5d756cf1fef3bc581.png)

等待安装程序自动完成安装，完成后点击“重启系统”  
![067f4538df4f796fbf4c6eb0d0aa61c2.png](/img/067f4538df4f796fbf4c6eb0d0aa61c2.png)

重启后，正进入系统  
![976a7b34e5cba9a5d1293794ccd93e29.png](/img/976a7b34e5cba9a5d1293794ccd93e29.png)

点击“许可信息”，勾选“同意许可协议”  
![5b6826048c3f9a85ed61ba4dff4c2312.png](/img/5b6826048c3f9a85ed61ba4dff4c2312.png)  

![6b3f5fc4ed71e7daa8e9b130e6ad61df.png](/img/6b3f5fc4ed71e7daa8e9b130e6ad61df.png)  

![3d17b2be8b20949b3585f46e3042aba6.png](/img/3d17b2be8b20949b3585f46e3042aba6.png)
